# [Tag]

> **一行要約: タグ文法は <>内容</> の形式で使用し、その文がどのような役割を果たすかを示し、その役割を付与します。**

---

## 1.コア概念
* **[Tag]: HTMLのコア文法として、<> と </> で文章を囲んで使用します。囲んだ中に該当するタグを入力することで、その文章に役割を付与します。** 

| 区分 | 特徴 | 参考 |
| :--- | :--- | :--- |
| **html** | <head> タグと <body> タグを囲むタグ。 | 特別な機能なし |
| **head** | 画面には表示されない基本設定タグを囲むタグ | 特別な機能なし |
| **body** | ブラウザ画面に直接表示されるタグを囲むタグ | 特別な機能なし |
| **title** | ブラウザのタブや検索結果に表示されるページタイトルを設定するタグ | - |
| **meta** | 画面には表示されない、ページの補足情報や初期設定を記述するタグ | - |
| **h1** | 見出しを指定するタグ | h1からh6まであり、数字が大きくなるほどサイズが小さくなります。|
| **li** | 文章をリスト化する。| - |
| **ul** | <li> タグをグループ化してまとめる。| - |
| **ol** | <li> を順序付きでグループ化する。 | - |
| **p** | 文章の段落を定義するタグ | 上下に余白がつく。|
| **br** | テキストを単純に改行するタグ | - |
| **img** | 画像を挿入するタグ | src属性で画像のURLを指定する必要があります。|
| **strong** | テキストを太字にして強調する。| - |
| **u** | テキストの下に下線を引く。| - |
| **a** | 他のサイトのリンクや、他のHTMLファイルを参照します。| href属性で参照先のアドレスを指定する必要があります。|

## 2.コード例
```<!DOCTYPE html baseline>
<html>
<head>
    <meta charset="UTF-8">
    <title>Webページのタイトル</title>
</head>
<body>
    <h1>見出し</h1>
    
    <p>
        これは文章の段落（pタグ）です。<br>
        brタグを使うと、このように<b>途中で改行</b>ができます。
    </p>

    <hr>

    <h2>画像の挿入</h2>
    <p>src 属性で画像のパスを指定します。</p>
    <img src="images/sample.png">

    <hr>

    <h2>リスト（順序なし）</h2>
    <ul>
        <li>リスト1</li>
        <li>リスト2</li>
        <li>リスト3</li>
    </ul>
</body>
</html>```
