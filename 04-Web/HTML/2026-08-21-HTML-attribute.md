# [Attribute]

> **一行要約: タグだけでは表現しきれない内容も、Attributeを使うことでより詳細に表現できます。**

---

## 1.コア概念
* **[Attribute]: 記述は開始タグ（<>）の中に行います。** 

| 区分 | 特徴 | 参考 |
| :--- | :--- | :--- |
| **charset** | 2進数で表現されたデータをどのように保存・表示するかを指定する属性 | metaタグで使用 |
| **href** | ハイパーテキストのリンク先を参照する属性 | aタグで使用 |
| **target** | タグをクリックした際、リンク先ページをどこで開くかを指定する属性 | _blank: 新規タブで開く、 _self: 現在のタブで開く |
| **title** | Webページの特定要素にマウスカーソルを乗せた際、ツールチップを表示する属性 | - |
| **style** | CSS構文を適用できるようにする属性 | - |
| **src** | 画像ファイルのアドレスを参照する属性 | imgタグで使用 |
| **width** | ブラウザ画面上の表示サイズを調整する属性 | px、% 単位を使用 |

## 2.コード例
```html
<meta charset="utf-8">

<h1><a href="test.html">HTML</a><h1>

<a href="https//..." target="_blank" title="HTML설명" style="color:red">HTML</a>

<img src="images.jpj" width="700px">
```
