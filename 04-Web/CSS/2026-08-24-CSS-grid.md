# [Grid]

> **一行要約: Gridは、Webページの要素をRowとColumnに分けて配置できるようにする2次元レイアウトシステムです。複雑な格子構造を簡単に作ることができます。**

---

<bar>

## 1.コア概念
* **[Grid]: Gridを使用するには、divやspanタグを使って2つ以上の要素を作成し、親タグ（div）でさらに囲みます。その親タグに display: grid プロパティを指定して使用します。**

* コード例
```html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>grid</title>
        <style>
            #grid {
                boder: 5px solid ponk;
                display: grid;
                /* 最初の列は150pxの幅を取り、残りのスペースをすべて使用する。（frは自動調整の単位）*/
                grid-template-columns: 150px 1fr
            }
        </style>
    </head>
    <body>
        <div id="grid">
            <!-- divタグは基本的にブロックレベル要素です。-->
            <div>NAVIGATION</div> 
            <!-- divと同じ目的で使用するインライン要素です。-->
            <span>ARTICLE</span>
        </div>
    </body>
</html>
```
* div: 特別な機能を持たず、純粋にデザイン（レイアウト）のために使用するタグで、ブロックレベル要素です。

* span: divと同じ役割を果たし、インライン要素です。
