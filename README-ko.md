## Documentation Language

일본어 학습과 병행하기 위해 개념 정리는 생성형AI를 활용하여 일본어로 작성합니다.

파이썬 문제풀이는 코드 중심이므로 효율적인 학습을 위해 문제풀이 파일의 주석이나 개선점은 한국어로 작성합니다.

저장소 내의 설명 파일은 모두 일본어로 작성되어 있습니다. 일부 중요한 파일은 복기 목적으로 한국어와 일본어로 두 번 작성했기 때문에 한국어로 번역하여 볼 수 있지만, 번역 기능이 없는 파일의 경우에는 크롬이나 엣지 브라우저의 우클릭 **'한국어로 번역'** 기능을 사용하시면 원할하게 읽으실 수 있습니다.

## Commit Convention

일관된 기록을 위해 아래의 방식으로 커밋합니다.

* **커밋 메세지 형식:**
  * 'docs: 2026-08-22: Java 객체지향개념 정리'
  * 'feat: 2026-08-22: PandasDataFrame 활용법'
  * 'fix: 2026-08-22: HTML태그 설명 수정'
* **파일명 형식:** 'YYYY-MM-DD-테마.md' (예시: '2026-08-15-Java-oop.md')
