# [Selector]

> **一行要約: セレクターは、スタイリングの対象となる要素をまとめて、効率よくデザインを適用するための構文です。**

---

## 1.コア概念
* **[Selector]: セレクターの種類には、tag、class、IDidがあります。** 

* セレクターのコード例
```html
<head>
    <style>
        /* 一般的なタグセレクター */
        a {
            color: black;
            text-decoration: none;
        }
        /* クラスがsawであるすべての対象の色をgrayに変更（必ず先頭に `.` を付ける）*/
        .saw {
            color: gray;
        }
        /* IDセレクターは `#` で表記する。*/
        #active {
            color: red;
        }
    </style>
</head>
<body>
    <ol>
        <!-- クラスはCSSではなくHTMLの文法です -->
        <!-- 1つのタグに複数のクラス属性値を指定できます。後に記述されたクラスの方が優先順位が高くなります。（※ 管理が難しくなるため非推奨）-->
        <li><a href="test.html" class="saw">HTML</a></li>
        <li><a href="test2.html" class="saw" id="active">CSS</a></li>
        <li><a href="test3.html">JavaScript</a></li>
    </ol>
</body>
```

---

## 2.セレクターの優先順位

| 優先順位 | 種類 |
| :--- | :--- |
| **1順位** | id | 
| **2順位** | class |
| **3順位** | tag |
- 同じ種類のセレクターの場合、最も最後に記述されたセレクターの優先順位が高くなります。

---

## なぜセレクターに優先順位が設定されているのか？

**IDセレクター**はウェブページ内で**一度だけ（唯一）**使用する必要があります。例えば、学校におけるIDが「学籍番号」であるように、IDは重複してはいけません。

まず**タグセレクター**を使って全体的なおおまかなデザインを作成し、その中の例外的な要素を**IDセレクター**でスタイリングします。そして、タグとIDの中間的な役割を果たす**クラスセレクター**を活用することで、効率的なコーディングが可能になります。
