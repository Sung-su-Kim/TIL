# [CSS - basic]

> **CSS要約: CSSはWebページを美しくデザインするための言語です。HTMLのタグだけでもWebページを飾ることは可能ですが、HTMLは「情報」としての役割を果たすときに最も価値を発揮します。単に見た目を整えるためだけのタグを多用すると、そのWebページは情報としての価値が低下してしまいます。そのため、HTMLが情報の記述に集中できるよう、 見た目の要素はCSSが担当します。CSSを活用することで、より効率的なデザイン作業が可能になります。**

---

## 1.コア概念
* **[CSS]: CSSはHTMLとは別の言語です。HTMLファイル内でCSSコードを使用するには、styleタグの中にCSSを記述する必要があります。** 

* HTMLファイル内でのCSSの使用例
```html
<head>
    <style>
        /* aタグ全体を対象に color を red に変更（保守性の向上）*/
        a {
            color: red;
            text-decoration: none;
        }
        /* aなどスタイルを適用する対象をselector、コードを囲む {} をdeclaration、color や text-decorationなどの効果を指定するコードをpropertyと呼びます。red や noneはpropertyのvalueです。*/
    </style>
</head>
<body>
    <ol>
        <li><a href="test.html">HTML</a></li>
        <!-- style属性を使って特定の要素のみを指定し、スタイルを変更 -->
        <li><a href="test2.html" style="decoration:underline">CSS</a></li>
        <li><a href="test3.html">JavaScript</a></li>
    </ol>
</body>
```
* HTMLでCSSを活用する方法には、HTMLのstyle属性を使用する方法と、styleタグでCSS構文を直接記述する方法があります。

## 2.基本的なプロパティの種類

| property | 特徴 | value |
| :--- | :--- | :--- |
| **color** | 文字の色 | red, yellowなど |
| **text-decoration** | 下線の有無 | none, underline |
| **font-size** | 文字のサイズ | px単位 |
| **text-align** | テキストの揃え | center, left, right |

## 3.学んだこと・感想
> 学習を通して学び、感じたことです。

* 質の高いコードを書くための基本は、重複を排除することである。コードの重複をなくすことでWebページの規模を簡素化でき、メンテナンス性が格段に向上するだけでなく、可読性も高まる。

* 易しく基本的なことと難しく複雑なことのうち、複雑なものは基本的なことの積み重ねで作られるため、基本のほうがより重要である。つまり、基礎をしっかり固めるべきである。

* 情報化社会の現代では、「何を知らないか」を正確に把握していれば、その知識は知っているのも同然である。例えば、CSSproperty概念を理解していれば、文字サイズの変更方法を知らなくても「CSS property font size」と検索するだけで1分以内に解決できる。「何が分からないか」を自覚し、検索一つで即座に補えるのであれば、それはもう自分の知識と言ってもよいのではないだろうか。
