## Commit Convention

一貫した記録のため、以下のルールでコミットします。

* **コミットメッセージの形式:** '[タグ] YYYY-MM-DD: テーマ'
  * 'docs: 2026-08-15: Javaのオブジェクト指向概念の整理'
  * 'feat: 2026-08-15: PandasDataFrameの活用法'
  * 'fix: 2026-08-15: HTMLタグ説明のタイポ修正'
* **ファイル名の形式:** 'YYYY-MM-DD-テーマ.md' (例: '2026-08-15-Java-oop.md')
