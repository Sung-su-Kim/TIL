## 1. 인공지능과 지능의 개념
* **[지능]:** 지능이란 학습, 이해, 추론을 통해 복잡한 문제를 해결하고 목표를 달성하는 능력을 의미한다. 이러한 지능은 환경으로부터 정보를 받아들이고 이를 처리하며 적절한 의사결정을 내리는 능력으로 정의될 수 있다.

* **[인공지능]:** 인공지능 (Artificial Intelligence)은 이러한 인간의 지능적 행위를 컴퓨터 프로그램을 통해 모방하거나 구현하는 기술이다. 즉, AI는 단순 계산을 넘어서 학습, 추론, 인식, 언어이해와 같은 고차원 기능을 수행하는 시스템을 포함한다.

## 2. AI, ML, DL의 계층적 관계
* **[AI]:** AI는 가장 상위 개념으로, 인간의 지능을 모방하는 모든 기술을 포함한다.

* **[ML]:** AI의 하위 개념으로 Machine Learning (ML)이 존재하며, 이는 데이터로부터 패턴을 학습하여 예측 또는 의사결정을 수행하는 방법론이다.

* **[DL]:** ML의 하위개념으로 Deep Learning (DL)이 존재하며, 이는 다층 인공신경망 (Deep Neural Network)을 활용하여 복잡한 비선형 패턴을 학습하는 기법이다.

## 3. Rule-based AI와 한계
초기 인공지능 시스템은 Rule-based 방식으로 구현되었다.
* **[Rule-based]:** 프로그래머가 직접 if-then규칙을 정의하여 문제를 해결하는 방식이다. 예를 들어, 특정 조건이 만족되면 특정 결과를 출력하도록 설계된다.
Rule-based방식은 다음과 같은 한계를 가진다.

1. 규칙폭팔 문제: 현실세계의 문제는 경우의 수가 매우 많기 때문에 모든 상황을 규칙으로 정의하는 것이 불가능하다.
2. 유연성 부족: 새로운 상황에 대해, 사전에 정의되지 않은 경우 대응이 불가능하다.
3. 확장성 문제: 시스템이 커질수록 규칙 간 충돌 및 관리비용이 증가한다.

특히 이미지 인식과 같은 문제에서는 조명변화, 객체변형, 가림, 클래스 내 변이 등으로 인해 동일한 객체더라도 다양한 형태로 나타나므로 Rule-based 접근은 근본적인 한계를 가진다.

## 4. 머신러닝의 개념과 학습과정
Rule-based의 한계를 극복하기 위해 등장한 것이 Machine Learning이다.

* **[머신러닝]:** 명시적인 규칙을 프로그래밍하지 않고, 데이터를 통해 모델이 스스로 패턴을 학습하도록 하는 기술이다. 기본적인 학습 과정은 다음과 같다. 1.데이터 수집 (Dataset 구성) 2.모델 학습 (Training) 3.예측 수행 (Inference) 여기서 핵심은 모델이 데이터로부터 입력과 출력의 관계를 학습한다는 점이다. 

* **[일반화]:** 머신러닝에서 가장 중요한 개념 중 하나는 일반화 (Generalization)이다. 이는 모델이 학습 데이터에만 잘 맞는 것이 아니라, 학습 시 보지 못한 새로운 데이터에서도 올바른 예측을 수행하는 능력을 의미한다. 일반화 성능이 부족한 경우 과적합 (Overfiting)문제가 발생하며, 이는 모델이 데이터의 본질적 패턴이 아닌 노이즈까지 학습한 상태를 의미한다.

* [ML구성요소]: 기계학습 시스템은 다음과 같은 구성요소를 가진다. 1.Dataset: 학습에 사용되는 데이터 집합. 2.Feature: 입력 데이터의 속성. 3.label: 정답값 (지도학습에서 사용, 모델이 예측해야하는 정답값) 4.Model: 입력을 받아 출력을 생성하는 수학적 구조. 5.Target: 모델이 수행해야하는 목표. 6. Trained Model: 학습을 통해 파라미터가 최적화된 모델. (학습 과정에서 모델의 내부 파라미터가 조정된다.)

* [Training & Inference]: 기계학습 과정은 크게 2단계로 나뉜다. 1.Training 학습: 데이터와 정답 (label)을 이용하여 모델의 파라미터를 학습하는 단계. 2.Inference 추론: 학습된 모델을 사용하여 새로운 입력에 대해 결과를 예측하는 단계.

## 5. 지도학습, 비지도학습, 강화학습
머신러닝 학습 방법에는 지도학습, 비지도학습, 강화학습 3가지가 존재한다.

* **[지도학습]:** Supervised Learning (지도학습)은 입력과 정답 (label)이 함께 제공된다. 입력과 출력 간의 관계를 학습하는 방법이며, 지도학습은 다시 분류 (classification), 회귀 (Rearession)으로 분류된다.

* **[비지도학습]:** Unsupervised Learning (비지도학습)은 정답 (label)이 없다. 데이터의 구조와 패턴을 탐색한다. 비지도학습은 다시 군집화 (clustering), 연관 (패턴파악)으로 분류된다.

* **[강화학습]:** Reinforcement Learning (강화학습)은 AI 에이전트가 환경과 상호작용하며 보상 (Reward)를 기반으로 최적의 행동 전략을 학습하는 방법이다. 구성요소로는 상태 (State), 행동 (Action), 보상 (Reward)가 있다.

## 6. 딥러닝과 인공신경망
머신러닝은 선형적인 문제만을 해결할 수 있고, 비선형적인 문제는 해결할 수 없다. 현실세계의 대부분의 문제는 비선형이므로, 이를 처리하기 위해 딥러닝과 같은 복잡한 모델이 필요하게 됐다.

■ 선형 (Linear): 입력과 출력이 직선 관계 ■  비선형 (Non-Linear): 복잡한 곡선 관계

* **[인공신경망]:** Artificial Neural Network (ANN) 인공신경망은 인간의 신경망 구조에서 영감을 받은 모델로, 여러개의 뉴런이 연결된 구조를 가진다. 각 연결에는 가중치 (Weight)가 존재하며, 입력 데이터에는 이 가중치를 통해 변환되어 출력으로 전환된다. Deep Learning은 이러한 ANN을 다층구조로 확장한 것이다. 여러 층을 거치면서 데이터는 점점 더 추상적이고 고차원적인 특징으로 변환되어 비선형적인 문제를 해결할 수 있게 된다.

딥러닝은 대규모 데이터, GPU기반 연산 능력 향상, 알고리즘의 발전으로 폭팔적으로 발전할 수 있었다.
