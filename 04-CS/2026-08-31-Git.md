## コミット関連コマンド
* **[git reset HEAD~1]：** 変更したコードはそのまま残し、コミットを取り消し（コミットと git add の状態を取り消し）

* **[git reset --soft HEAD~1]:** ステージング状態を維持したままコミットを取り消し。ステージングに残るため、コミットメッセージだけを修正して再コミットしたい時に便利

* **[git reset --hard HEAD~1]:** 変更したコードも含めてすべて削除し、直前の状態に復元

* **[git commit --amend -m "新しいコミット"]:** 直前のコミットメッセージの変更や、追加し忘れたファイルを含めて上書きコミット

* **[git revert HEAD]:** 既に GitHub にプッシュ済みのコミットを取り消し（既存のコミット履歴を削除せず、「以前のコミットを取り消す」という新しいコミットを作成して安全にリモートリポジトリへ反映。チーム開発時に reset して push -f するとコンフリクト（衝突）が発生するため revert を使用）
